# Support

Need help with one of my projects? Here are the best places to start.

## Questions and troubleshooting

First, check the repository's README, documentation, and existing issues.
Your question may already be answered there.

If you still need help:

- If something appears to be broken, open a **bug report**.
- If you have an idea for an improvement, open a **feature request**.
- For other project-related questions, you may open a blank issue if the
  repository allows them.

When asking for help, include whatever details are relevant, such as:

- What you're trying to do
- What happened instead
- The project/version you're using
- Your browser, operating system, application, or other relevant environment
- Any error messages or screenshots that may help

Please remove passwords, tokens, private information, and other sensitive
data before posting screenshots or logs.

## Security issues

Please do **not** report suspected security vulnerabilities in a public issue.

See the
[security policy](https://github.com/BluestockingsRead/.github/blob/main/SECURITY.md)
for reporting instructions.

## Response time

These projects are maintained as time and interest allow. I appreciate
questions and reports, but I can't guarantee a particular response time.

Thanks for using my projects! 💛
