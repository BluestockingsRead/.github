# Contributing

Thanks for your interest in contributing!

Bug reports, suggestions, documentation improvements, and pull
requests are welcome. Individual repositories may have additional
project-specific guidance.

## Before you start

- Check the README and existing issues first.
- Search for an existing issue before opening a new one.
- For small fixes, feel free to open a pull request directly.
- For larger changes or new features, consider opening an issue first
  so we can discuss the idea before you spend a lot of time on it.
- For security vulnerabilities, please do **not** open a public issue.
  See the [security policy](https://github.com/BluestockingsRead/.github/blob/main/SECURITY.md) instead.


## Bug reports

A useful bug report includes, when relevant:

- What you expected to happen
- What actually happened
- Steps to reproduce the problem
- The project/version you're using
- Your operating system, browser, application, or other relevant
  environment details
- Screenshots, console errors, logs, or example URLs if they help
  explain the problem

Please remove passwords, tokens, private data, and other sensitive
information before posting logs or screenshots.

## Feature requests

Feature ideas are welcome.

It helps to explain the problem you're trying to solve, not just the
specific implementation you have in mind. There may be another way to
solve the same problem that fits the project better.

## Pull requests

Please keep pull requests reasonably focused.

When submitting a change:

- Explain **what** changed and **why**.
- Avoid unrelated formatting or refactoring when possible.
- Follow the existing style and structure of the project.
- Preserve useful comments unless they are no longer accurate.
- Add or update documentation when behavior changes.
- Test the relevant behavior before submitting the pull request.
- Mention any limitations, edge cases, or testing you could not
  perform.

Small, clear pull requests are generally easier to review than several
unrelated changes bundled together.

## A note on scope

These projects are maintained as time and interest allow. Suggestions
are appreciated, but submitting an idea does not guarantee that it
will be implemented.

Thanks for helping make things better. 💛
