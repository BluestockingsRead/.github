# GitHub Defaults

Shared community health files and repository defaults for my public
GitHub projects.

GitHub uses supported files from this repository as defaults when an
individual repository does not provide its own version.

## What's here

- `CONTRIBUTING.md` — general contribution guidelines
- `SECURITY.md` — security reporting guidance
- `SUPPORT.md` — where to ask questions and get help
- `CODE_OF_CONDUCT.md` — community standards
- `.github/ISSUE_TEMPLATE/` — default bug and feature-request forms
- `.github/pull_request_template.md` — default pull request guidance
- `FUNDING.yml` — GitHub Sponsors configuration

Individual repositories may provide project-specific versions of any
of these files when different guidance is needed.
