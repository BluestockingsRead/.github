# Bluestockings Read

**free, user-friendly tools for people who read too much and tinker too much.**

Hey, I'm the dev behind BluestockingsRead. My special interests include reading,
and also... *everything*. I'm a book nerd (with the requisite book blog) and I
make tools for fellow readers. Usually because I wanted something that didn't
exist, and because I could. Isn't that why we're all here?

Everything here is free, open, and stays that way. No paywalls, no secret VIP
rooms, no compulsory patron side quests.


## What lives here

| Project | What it does | Status |
|---|---|---|
| **[Accio Books](https://github.com/BluestockingsRead/Accio-Books)** | Multi-site book search: One query, many catalogs, fewer tabs | 🟢 Live |
| **[Naked Details](https://github.com/BluestockingsRead/Naked-Details)** | A tiny userscript that automatically expands `<details>` elements on websites | 🟢 Live |


## Also on deck

- **GreatReads**: browser extension for Goodreads, adding the customization and
  quality-of-life bits they forgot
- **Hyperfixation Type**: fixation-point fonts for faster, easier reading; plus
  the tools to build and analyze them
- A major **Accio Books** glow-up
- A WordPress **spoiler-tag plugin**, because "click to reveal" shouldn't
  require a page builder


## The design philosophy 🧐

Simple-to-use tools that don't ask for an account. Readable source. Comments
written for the person who has to come back in six months. (Usually me, usually
with no memory of why any of this exists.)

If something here is broken, the issue tracker is open and I promise not to be
weird about it.
